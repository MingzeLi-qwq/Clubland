\subsubsection{Business objectives}\label{business-objectives}

This project aims to provide student societies with a secure,
privacy-focused alternative to mainstream social media platforms for
managing their online presence. By creating a dedicated web application,
societies can centralize membership tracking, news sharing, and event
coordination while avoiding the data exploitation and polarization
prevalent on third-party platforms. Universities and student unions gain
oversight capabilities to approve, monitor, or revoke society pages,
ensuring alignment with institutional guidelines. The platform
prioritizes branding flexibility, allowing societies to tailor their
pages to reflect their unique identities and organizational needs,
fostering inclusivity for diverse groups ranging from academic clubs to
competitive teams.

\subsubsection{System Statement}\label{system-statement}

Built as a scalable Django web application, the platform operates 
across desktop and mobile browsers, utilizing Python for backend 
logic with Django's ORM managing SQLite databases. 
The frontend combines HTML/CSS templates with React-based interactive components, 
enhanced by Django-summernote's rich text editing for content management systems. 
Modular architecture enables:
\begin{itemize}
\item Dynamic widget customization through React Grid Layout
\item RESTful API integrations via Axios
\item Progressive enhancement with Vite-built frontend modules
\end{itemize}
Authentication and permissions leverage Django's built-in tools, while container-ready deployment supports both on-premises and cloud infrastructure.
