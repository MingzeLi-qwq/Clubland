\chapter{Testing}
\label{chap:testing}

\section{Approach and tools}
\label{sect:testing:approach}
In this project, we primarily relied on the Django testing framework for
automated testing, which included the following types of tests:

\begin{itemize}
\item
  \textbf{Unit Testing}: Testing core functional modules to ensure the
  correctness of each module.
\item
  \textbf{Integration Testing}: Verifying interactions between
  apps to ensure that various modules work together properly.
\item
  \textbf{User Interface Testing}: Ensuring the responsiveness and
  usability of the user interface (tests focused on template rendering).
\item
  \textbf{Security Testing}: Checking for potential security
  vulnerabilities to ensure system security (tests focused on mixins and
  other security restriction tools).
\end{itemize}

\section{Quality assurance processes}
\label{sect:testing:process}
To ensure the quality of our tests, we used test coverage tools for
coverage detection. Currently, the test coverage for the entire project
reaches 92\%, with all tests passing successfully, ensuring the stable
operation of the main functionalities.

The test coverage report can be viewed in ./htmlcov/index.html


\section{Evaluation of testing}
\label{sect:testing:evaluation}
In our testing evaluation, we identified the following strengths and
weaknesses:

\begin{itemize}
\item
  \textbf{Strengths}:

  \begin{itemize}
  \item
    Unit tests and integration tests covered most of the core
    functionalities, ensuring their correctness.
  \item
    The main user interface templates were tested, ensuring usability.
  \end{itemize}
\item
  \textbf{Weaknesses}:

  \begin{itemize}
  \item
    Some complex functionalities had insufficient test coverage and need
    further improvement. For example:

    \begin{itemize}
    \item
      Widget functionality in Club Hub
    \item
      Message chat functionality between users in the Message system
    \end{itemize}
  \item
    The tests that could not be automated were compensated through
    Manual tests, please see Appendix A - Manual tests
  \end{itemize}
\end{itemize}
